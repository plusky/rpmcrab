# Curated spelling corrections: misspelling -> correction, one per line.
#
# Mined from lintian's corrections list (data/spelling/corrections in
# https://salsa.debian.org/lintian/lintian.git, revision
# f0cbdc517ff8c184fe7f818071025ba162737d06, 2026-11-12) by
# scripts/mine-spelling-corrections.py. Lintian's list carries
# misspellings observed in the wild in package descriptions, which is
# exactly the prose this checker reads.
#
# Mining rules (see the script): both sides a single lowercase ASCII
# word; misspelling and correction differ; Levenshtein distance at most
# 3 (far-apart pairs are usually a wrong mapping, not a typo); a
# misspelling the shipped supplementary wordlist already accepts is
# dropped; two entries whose lintian correction is flatly wrong are
# dropped by name. Every entry is verified live against the pinned
# en_US dictionary by the
# `corrections_are_live_against_the_pinned_dictionary` test: the
# misspelling is rejected and the correction accepted, so a listed
# correction is always a real word and the misspelling is always
# actually flagged.
#
# The miner also reads codespell's dictionary
# (https://github.com/codespell-project/codespell, revision
# 4d354de4425d686bf603381a7dc39e4e0234291d, 2026-11-10); its entries are
# not shipped here -- general code typos, held for a follow-up quality
# pass -- but the script merges them by the same rules when given.
#
