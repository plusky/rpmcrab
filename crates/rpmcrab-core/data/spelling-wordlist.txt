# Supplementary spelling vocabulary for the spellchecker.
#
# The hunspell dictionary the checker loads (the pinned en_US
# dictionary of scripts/install-hunspell-dicts.sh) lacks these words,
# so package prose using them correctly was reported as a spelling
# error. Every entry was verified against that dictionary: a word it
# accepts is not listed.
#
# Package descriptions are en_US text, so this list follows en_US:
# British spellings are not listed; they stay flagged (at warning
# level) for packagers to fix in the prose.
#
# An entry carries hunspell affix flags where the word's derivations
# are regular, so one line covers its family: the flags resolve
# against the loaded dictionary's own affix rules (in the pinned
# en_US set, S is the plural, D the -ed form, G the -ing form,
# R/Z the -er forms, M the possessive). A plain entry covers exactly
# the written form.
#
# The list is deliberately curated: every entry is an ordinary
# English word, an established technical term of the computing and
# packaging domain, or ecosystem vocabulary that package prose uses
# as common nouns. Genuine misspellings are never listed, however
# many packages repeat them; package-specific names and library
# identifiers are not listed either.
#
# Curated from the flagged-word histogram of the 2026-10-24 Factory
# corpus sweep (34,596 findings at main 38459d25): an entry had to be
# flagged in at least five source packages' prose, or complete a
# family begun by such an entry.
