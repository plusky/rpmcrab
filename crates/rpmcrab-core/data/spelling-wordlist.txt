# Supplementary spelling vocabulary for the spellchecker.
#
# The hunspell dictionaries the checker loads (the pinned en_US and
# en_GB pair of scripts/install-hunspell-dicts.sh) lack these words,
# so package prose using them correctly was reported as a spelling
# error. Every entry was verified against that pair: a word either
# dictionary accepts is not listed.
#
# The list is deliberately small and curated: every entry is an
# ordinary English word, an established technical term of
# the computing and packaging domain, or ecosystem vocabulary that
# package prose uses as common nouns. Genuine misspellings are never
# listed, however many packages repeat them; package-specific names
# and library identifiers are not listed either. British spellings
# are accepted via the en_GB dictionary instead and appear here only
# where that dictionary lacks the stem entirely.
#
# Curated from the flagged-word histogram of the 2026-10-24 Factory
# corpus sweep (34,596 findings at main 38459d25): an entry had to be
# flagged in at least five source packages' prose, or complete a
# family begun by such an entry.

# British spellings the pinned en_GB dictionary does not carry.
